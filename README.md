# Anbumani T. — Portfolio Website

A responsive personal portfolio made with HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — colours, layout and responsive styling
- `script.js` — mobile navigation and scroll reveal effects

## Publish with GitHub Pages
1. Create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload all three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the site to publish at `https://YOUR-USERNAME.github.io`.

## Personalize before publishing
Search `index.html` for placeholder text such as:
- `your.email@example.com`
- `Your degree / course`
- `Institution name`
- `Add your category`
- `YOUR TOOLS / SKILLS`

Replace those with your real details. Also update your GitHub and LinkedIn links.

This is a static website; no build tools or coding setup are required.
